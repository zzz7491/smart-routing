# SmartRouting · 共享分流规则（公开模板版）

Clash Verge 与 Shadowrocket 共用的一套分流规则与策略组模板：以完整版配置为基线恢复而来，公开仓库只放**无凭据模板**，完整节点与订阅在私有仓库与受保护的订阅服务中。

## 规则规模（与完整版一致）

- Clash 分流规则 **544 条**，原相对顺序保留；
- Shadowrocket 重写 **807 条**，含全部 Host 与解密域名；
- 策略组与模板结构与完整版一致，仅剔除节点与凭据。

## 仓库内容

```
├── clash.template.yaml   # Clash 模板（规则 + 策略组，无节点凭据）
├── shadowrocket.conf     # Shadowrocket 模板（重写 / Host / MITM 域名）
├── rules/                # 分流规则集
├── build.py              # 模板构建脚本
├── policy.json           # 策略定义
├── 恢复与逐条核验报告.md   # 恢复过程与核验结论
├── 逐条完整性检查.csv     # 逐条核验明细
└── 完整性核验.json        # 核验结果数据
```

## 使用说明

- 本仓库的模板**不是可直接导入的完整订阅**：导入前需填入自己的节点信息；
- 不要把旧公开链接当作机场式完整订阅使用；
- 完整配置（含节点）只存放在私有仓库 `smart-routing-private`，通过受保护的 Cloudflare Workers 订阅地址分发。

## 核验说明

- 原规则中的重复、被覆盖及疑似过时域名仅记录在核验报告中，未擅自删除；
- 28 条脚本引用资源已失效（404），原定义保留为注释；
- 公开文件不含任何节点密码或 CA 证书。
